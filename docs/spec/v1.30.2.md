# WARPIX製作所 ホームページ 仕様メモ v1.30.2「まんなかへ もどらない」

- **タグ**：`v1.30.2`（2026-11-06）
- **ひとこと**：スマホで 絵を よこに 見て いる とき、ページを スクロールすると まんなかへ もどって しまう のを 直した
- **前のバージョン**：[v1.30.1](v1.30.1.md) ／ [バージョン一覧](README.md)

## なぜ

- 本人が iPhone の 実機で「よこに スクロールしたら まんなかに もどされる」
- iPhone は ページを スクロールすると アドレスバーが 出入りして、画面の たかさが かわり `resize` が くる。そのたびに `fit()` が 絵を まんなか（ゲンさんたち）に 置きなおして いた
- 手元で 再現：◀ ▶ で みぎはしへ（262）→ たかさだけ 740→660 に かえる → 154（まんなか）に もどった

## v1.30.1 からの変更

- **`factory.js`**：`resize` の とき、絵の はばが かわって いなければ `fit()` しない（`fitW`）。はばが かわる とき（よこむきに した など）は これまで どおり 合わせなおす
- **`tests/home.test.mjs`**：スマホの ひっぱる テストに「たかさだけ かわっても まんなかへ もどらない」を 足した（件数は そのまま）
- 文字は ふえない
