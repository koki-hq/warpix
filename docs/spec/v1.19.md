## v1.18 からの変更

- **変更**：`index.html` の 展示室（warpix-link）
  - ひとこと：「いつもの 公式サイトへ、ドット絵の ピクセと いっしょに ワープする 踏み台リンクアプリ。」
  - できる ことは 3 つ（ワープ・そだつ・あそぶ）を 1 行ずつ。「こんな ひとに」「つかいかた」と 見出しは なくした
  - 値札（`ex-plate`）は 3 行：ねだん・うごく ところ・きろく
  - 「ピクセと WARPIX の 名前・絵は WARPIX製作所の ものです。」は 小さく のこす（`.ex-note`、権利の ことわり）
  - ドット絵・レトロ・チップチューンの ことばは のこした
- **追加**：ショーウィンドウの ピクセ（`.ex-window` の `.ex-warp`、warpix-link への リンク）。いつも「いってみる？」の ふきだし。
  おすと ワープあなが ひらいて ピクセが とびこみ（0.7 秒、1 回だけの CSS アニメーション）、warpix-link へ。
  へらした うごき・Ctrl などを おした とき（新しい タブ）は ふつうの リンク。もどる ボタンで もどったら もとどおり（`pageshow`）
- **変更**：`style.css`：`.exhibit h4`・`.ex-steps` を けし、`.ex-window`・`.ex-warp`・`.ex-note` を 足した
