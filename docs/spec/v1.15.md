## なぜ Press Start 2P は Google の まま か

どちらも SIL Open Font License 1.1。ただし Press Start 2P には **予約された フォント名（RFN）** が ある。
OFL FAQ 2.6：「webfont の 文字を しぼるのは 改変。OFL では ゆるされるが、ふつうは RFN を つかえない」。
しぼった ものを「Press Start 2P」の 名前で 自分で 配る ことは できない ので、Google Fonts から 読む ままに した。
DotGothic16 は RFN が ない ので、しぼって 置いて いい（ライセンスの 文を いっしょに 置く）。

## はやさ

スマホの 遅めの 4G の まね（150ms・1.6Mbps、CPU 4 倍遅く）、本番の ように gzip で かえす 手元の サーバー、3 つを こうごに 6 回。まんなかの 値：

| | 最初に 表示（FCP） | ドットの 文字が でる |
|---|---|---|
| v1.14（Google Fonts） | 1.16 秒 | 1.35 秒 |
| preload あり | 1.23 秒 | 1.59 秒 |
| **v1.15（preload なし）** | **1.14 秒** | **1.21 秒** |

- preload を つけると、Chrome が フォントを 待ってから 描くので かえって おそく なった
- 差は 小さい（ドットの 文字が 0.1 秒ちょっと はやい）。Google に とりに いく ものが 1 つ へった（DotGothic16 の CSS と ファイル）
- テストの サーバーは gzip しないので、JS が 大きく 見えて フォントの 差が わからない。はかる ときは gzip で
