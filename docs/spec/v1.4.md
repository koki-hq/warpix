## おせる 生き物と 遺跡

おすと 画面の 下の まど（`#toast`）に ことばが でる（4 秒 ＋ 1 文字 60ms で きえる）。

| もの | ことば |
|---|---|
| ミミズ | 「にょろにょろ。（ミミズは 土を ふかふかに する はたらきもの）」 |
| ホリマル | 3 つ じゅんばんに（カセット みつけた／ドリルを みがく／もっと したに ひかる まち） |
| スイショウクラゲ | クラゲが 8 コマ ぱあっと 光る。「ふわ〜ん（ほんのり つめたい）」 |
| トモシビ族 | 1 人目「ようこそ、ちじょうの ひと。ここは ひかりの まち。」、2 人目「石板の かけらを 5 つ あつめて、はじまりの 像に みせて ごらん。」（ヒント） |
| ひかる 目の 神殿 | 「じっと こっちを 見ている……古代文字は まだ よめない。」→ 伝説の あとは「やさしく まばたきした。」 |
| 石の ピクセ像 | 「足もとに「はじまりの……」と ほってある。のこりは けずれて よめない。（石板の かけら n／5）」→ 伝説の あとは 伝説を もう一度 |

置けなかった もの（はばが せまい とき など）は ボタンも ない。石像は 置けなければ 深い 空洞へ。

## 石板の かけら

- 地層ごとに 1 つ（表土・粘土・洞窟・古代文明・最深部）。8×7 ドット、古代文字が 光る
- 置く 場所：その 地層の パネルに かからない ところ → だめなら 洞窟の 空洞 → 深い 空洞（スマホでも 5 つ そろう）
- 読み上げの 名前：「石板の かけら（ちか 120m）」など
- おすと 消えて「石板の かけらを みつけた！（n／5）」
- 5 つ目で 伝説：

> 『むかし、ちていの やみに、ドットの こびとが うまれた。
> こびとは トモシビ族に あかりの つくりかたを おしえ、
> やがて ひかりを もとめて、そらへ のぼっていった。
> いつか ちじょうで、ものを つくる ために。』

- 伝説の あと：石像の 目が ずっと 光り、まわりが きらきら。地上の ピクセは つぎに おされた とき「……地下の 石板？ なんだか、なつかしい かんじが する。」（`warpix:legend` イベント）
- **その場かぎり**。ページを ひらきなおすと また さいしょから（ブラウザに 保存しない 約束）
- 伝説は ピクセの からだ（プロフィール）を 変えない。ピクセ族の ルーツの「なぞ」として 足した もの
