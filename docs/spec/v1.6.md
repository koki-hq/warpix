## warpix-link の 展示

- 絵：warpix-link の 共有カード（`https://koki-hq.github.io/warpix-link/og.png`、1200×630、26 KB、`loading="lazy"`）。おすと warpix-link へ
- だいいちだん・かどうちゅう（ランプは 工場の とけいで 点めつ）
- ひとこと：「いつもの 公式サイトへ、ピクセの いる 空間を とおって ワープする 踏み台リンクアプリ。」（v1.0 の まま）
- こんな ひとに：いつも 見る 公式サイトを 1 つの ページから ひらきたい ／ ドット絵・レトロゲーム・チップチューンが すき ／ リンクを ひらく たびに ちょっと たのしく なりたい
- できること：リンクは 6 こ（たなの 公式リンクから いれかえ）／ ワープ（ピクセも ワープあなに とびこむ）／ ピクセが そだつ（成長・日記・おへや）／ あそび（ミニゲーム・冒険・さっきょく・おみくじ）／ リンクだけ みる（シンプルモード）／ アプリに なる（ホーム画面・オフライン）
- つかいかた：PRESS START（リンクだけ なら「リンクだけ みる」）→ リンクを おして ワープ → 気に いったら ホーム画面に
- 製品の 札：つかえる ところ（ブラウザ、ホーム画面で アプリ）／ ねだん（むりょう）／ きろく（その ブラウザの 中だけ、ふっかつの じゅもんで ひっこせる）／ コード（MIT、ピクセと WARPIX の 名前・絵は WARPIX製作所）
- ボタン：「warpix-link を ひらく」、「コードを 見る（GitHub・MIT）」
- 中身は warpix-link の README（v1.28 の とき）を もとに 書いた。数（実績の 数・公式リンクの 数 など）は かわりやすい ので 書かない
- スマホでは 絵 → 紹介 → 札 の じゅんばん
