# WARPIX製作所 ホームページ 仕様メモ v1.10「かるい フォント」

- **タグ**：`v1.10`（2026-10-16）
- **ひとこと**：このページで つかう 文字 だけの フォントを たのむ ように して、最初の 表示を かるく
- **前のバージョン**：[v1.9](v1.9.md) ／ [バージョン一覧](README.md)

ここには v1.9 から変わったところだけを書きます。

## v1.9 からの変更

- **追加**：`tools/fonts.mjs`（つかう 文字を あつめて フォントの リンクを つくる）、テスト 1 件（合計 14 件）
- **変更**：`index.html` の フォントの リンク（`<link id="font">`）に `text=`（つかう 文字）を つける

## しくみ

- `index.html`・`factory.js`・`chika.js`・`radio.js`・`news.json` に でてくる 文字（ASCII 以外）と、ASCII の 見える 文字 ぜんぶ を あつめる（いまは 461 文字、URL は 約 3,500 文字）
- Google Fonts は その 文字 だけの フォントを 2 つ（Press Start 2P と DotGothic16）かえす。まえは 日本語の フォントが 文字の 種類ごとに 約 30 こに わかれて とどいていた
- **文字を ふやしたら かならず `node tools/fonts.mjs`**（news.json の おしらせ、セリフ、文章）。ながさないと、その 文字だけ ふつうの 字に なる。テスト「フォント：このページで つかう 文字が ぜんぶ…」が たりない 文字を おしえる
- `node tools/fonts.mjs --check` で しらべる だけも できる
