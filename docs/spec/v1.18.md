# WARPIX製作所 ホームページ 仕様メモ v1.18「開店の じゅんび（11/1 7:00 に 自動で 開店）」

- **タグ**：`v1.18`（2026-10-18）
- **ひとこと**：開店いわいの かざり（くすだま・紅白幕・花輪）と X・Instagram の 入口を 入れて おき、**2026-11-01 7:00（日本時間）に 自動で ひらく**。同じ 時刻に GitHub Actions が 製作所だよりへ「開店しました」を のせて v2.0 に する（→ v1.27 で、SNS は 開店まえから 出し、v2.0 の タグは つけない ことに した）

## 開店の しくみ（ユーザーと 決めた、2026-10-18）

- 開店は 2026-11-01（日）の あさ 7:00（事務所の 開店の 計画「朝に 開店の 投稿」に あわせた）
- ページは 時計で 切りかわる（`factory.js` の `OPEN`）：7:00 から かざり・開店の ことば・SNS の 入口
  - SNS の リンクは HTML に もう ある（`hidden`）。見ている 人には 7:00 まで 出ないが、ソースを 見れば わかる（ユーザー OK）
- おしらせは `.github/workflows/open.yml`（cron `0 22 31 10 *` = 日本時間 11/1 7:00）が `node tools/open.mjs` を ながす：
  `tools/open-news.json` を `news.json` の いちばん 上に のせ、コミット「v2.0: open …」、タグ `v2.0`、push、Pages の 公開を 頼む
  - 7:00 まえ・もう のって いる ときは なにも しない（手で「Run workflow」しても あんぜん。まいとし 10/31 22:00 UTC に うごくが なにも しない）
  - GitHub の 予約は 混むと おくれる ことが ある。おそい ときは Actions の 画面から「Run workflow」
  - **warpix-link の ウィンドウは 開店の 下書きを 書かない**（2 本に ならない ように。もし 書かれても id `2026-11-01-open` が おなじ なので のせない）
  - `tools/open-news.json` の 文字は `tools/fonts.mjs` が さきに フォントへ 入れて おく
