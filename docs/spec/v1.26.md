## v1.25 からの変更

- **`count.js`（あたらしい）**：`window.WARPIX_COUNT = { token, host: "warpix.app" }`。`location.hostname` が `host` で トークンが ある ときだけ `https://static.cloudflareinsights.com/beacon.min.js` を `data-cf-beacon` つきで よむ（`spa: false`）。てもと・テストでは なにも しない。warpix-link の `count.js`（v1.65）と おなじ 形
  - トークンは Cloudflare の Web Analytics の サイト「warpix.app」（JS Snippet installation。warpix.app は DNS only なので 自動の うめこみは きかない）。ページに のせて いい 公開の 値
  - SNS の プロフィールの リンクは link.warpix.app の 入口（`/x/` `/ig/` `/tt/` `/yt/`、warpix-link v1.65）。ホームページには 入口を 作って いない
- **じむしょ「このページが のこすもの」**：「なんにん きたか だけ、Cloudflare で かぞえて います（クッキーは つかわず、だれかは わかりません）。」を 足した。おしらせ・SNS では 発表しない（こっそり 正直に）
- **ホーム画面の アイコン**：`tools/favicon.mjs` が `favicon.svg` に くわえて `icons/apple-touch-icon.png`（180、ドット 10 ばい）・`icons/icon-192.png`（8 ばい）・`icons/icon-512.png`（20 ばい、maskable の まんなか 8 わりに おさまる）と `manifest.webmanifest` も 作る。背景は 青空の `#2f86e6`（theme-color）。PNG は Node の zlib だけで 書く
  - `manifest.webmanifest` の `display` は `browser`（ホーム画面から ひらいても ふつうの ブラウザ。アプリの ような PWA には しない）
  - `index.html` に `<link rel="apple-touch-icon">` と `<link rel="manifest">`
- `fonts/`：あたらしい 文字で つくりなおし
