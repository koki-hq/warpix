- **前のバージョン**：[v1.32](v1.32.md) ／ [バージョン一覧](README.md)

## なぜ

- Mac に うつって から、テスト用の ヘッドレス Chrome が ときどき へんじを しなく なり、テストや 健康診断が 何分も 止まった（11/13 だけで 3 回、CPU は ひまな まま。原因 不明）
- 本人「対策しておいて　これから」

## v1.32 からの変更

- **`tests/lib/harness.mjs`**：Chrome への 問いかけ（CDP）が 60 秒 へんじ しなければ `STALL:` の エラーに（止まった まま に しない）
- **`tests/run.mjs`**：ふだんは 1 ファイルずつ、ファイルごとに 子プロセスで ながす。6 分 おわらない・`STALL:` が でた ときは、テスト用 Chrome を かたづけて 1 回だけ やりなおす。2 回 とも 止まったら 失敗。ふつうの しっぱいは やりなおさない（本当の 失敗を かくさない）。`--jobs 4` で これまでの 同時ながしも できる。`WARPIX_FILE_LIMIT_S` で 打ち切りを みじかく して しくみを ためせる
- **`tools/health.mjs`**：自分を 子プロセスで うごかし、2 分で 打ち切って 2 回まで やりなおす
- わざと 止まる テストで、打ち切り → やりなおし →「2 回 とも 止まった」→ Chrome 0 を 確かめた
- ページ（`index.html`・`*.js`・`style.css`）は かわらない
