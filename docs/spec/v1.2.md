## 青空の 工場まち（`factory.js`）

### 大きさ

- 絵は **480×176 ドット**。倍率は `max(2, ceil(画面の はば ÷ 480))`。はみだす ぶんは 左右を けずる（まんなかは x=244、ゲンさんたちの あたり）
- 例：1440px → 3 倍（ぜんぶ 見える）、390px → 2 倍（x 146〜341 だけ 見える）
- うごかない 景色は 3 まいに 分けて 1 回だけ 描く：うしろ（空・おひさま・入道雲）／ なか（山・丘・町・高架）／ まえ（クレーン・足場・電柱・時計塔・えんとつ・本工場・看板の わく・倉庫・じめん・ひまわり・自販機・木箱）
- 毎コマ：うしろ → 雲・鳥・飛行船 → なか → 電車・ドローン・けむり → まえ → うごく もの

### おせる ところ

すきとおった `button` を 絵に かさねる（最小 24px）。絵の 外に 出た ボタンは `hidden`。

| ボタン | ことば |
|---|---|
| ピクセ（`#pikuse-btn`、お話に あわせて うごく） | 8 つの セリフを じゅんばんに（ドットを くみたてる、ブルーシートの 中は ひみつ、ヘルメット、チップチューン、けいじばん、warpix-link の きょうだい、なかま図鑑、えんとつ）。にっこり 顔に なる |
| ゲンさん（`#oji-btn`） | 4 つ（いらっしゃい、ピクセは よく はたらく、むかしの 道具も 未来の 機械も、ピコピコ した 音楽） |
| えんとつ | 「ぽっぽー！」→ 5 回で「フルかどう！」→ 10 回で「けほっ けほっ」。けむりが もくもく |
| ねこ（`#cat-btn`） | 「にゃあ」「……zzz」「ふにゃ（ひなたぼっこ ちゅう）」 |

- ことばは 絵の ふきだし（`.say`、読み上げ しない）と、読み上げ用の `#bubble`（`role="status"`、「ピクセ「…」」「ゲンさん「…」」「トタン「…」」）の 両方に
- 開いた ときの あいさつ（ピクセ）：0〜4 時「よふかしだね。こっちは いつでも 晴れてるよ。」、5〜10 時「おはよう！…きょうも ドットを くみたてるよ。」、11〜18 時「こんにちは！…ぼくや ゲンさんを おすと おはなし できるよ。」、19〜23 時「こんばんは！…こっちは まだ 晴れてるよ。」

## 地面の 下の 世界（`chika.js`）

- `.underground` を `header` の 下から ページの いちばん 下まで しく。倍率は 地上と おなじ
- 地層の さかいめは パネルと 空洞の 場所に あわせる：

| 地層 | はじまり | 左の 目もり | ある もの |
|---|---|---|---|
| 表土 | いちばん 上 | -10m | 木の 根、ミミズ（うごく）、工場から おりる パイプ、ブリキの ロボット |
| 粘土 | せいひん・だより の 35% の 高さ | -120m | アンモナイト、魚の 骨、恐竜の 頭、カセットテープ、ゲームカセット、ホリマル（ドリルで ほる） |
| 洞窟 | 空洞（洞窟）の 少し 上 | -800m | つらら・石筍、光る キノコ（胞子）、大きな 水晶（きらっ）、滝の ある 地底湖と スイショウクラゲ |
| 古代文明 | 図鑑の 60% か、空洞（深い）の 上 | -3000m | 岩の 町（窓の あかりが ちらちら）、光る 目と 古代文字の 神殿、歯車（まわる）、トモシビ族（ランタンを もって あるく）、ピクセそっくりの 石像（ときどき 目が 光る） |
| 最深部 | 空洞（深い）の 62% | -????m | ホタルミミズの トンネル（トモシビ族が のって はしる）、マグマの すじ（脈うつ） |

- パネル・案内・けいじばん・フッターの まわりは 掘った 部屋（暗い ふち）。高い パネルは 坑道の 木わくで ささえる
- 生き物や 遺跡は、パネルに かからない 場所を さがして おく（いつも おなじ 乱数で、毎回 おなじ 景色）。画面の はばや 高さが かわったら 描きなおす（`ResizeObserver`、フォントと お知らせの 読みこみ後）
- 空洞：洞窟 150px、深い ほう 260px（`.hollow`）。スマホでも 見せ場が 見える
- 景色は 1 回だけ 描いて 写しを とり、毎コマ **画面に 見えている** うごく もの だけ、景色を もどしてから 描く

## かわらない 約束

- 製作所だより：`news.json`（`{ "news": [{ "id", "date", "title", "body"?, "url"? }] }`）を 日付の 新しい 順に。14 日 以内は NEW。こわれた もの（日付・タイトル なし）は とばす。読めない ときも こわれない
- ブラウザに なにも 保存しない（フォントだけ Google Fonts）
- アクセシビリティ：axe-core で 問題 0。絵は `role="img"` と 説明、おせる ところは キーボードで たどれる
- 電池：うごく ものは ぜんぶ 0.3 秒ごとの 工場の とけい 1 つ。地上の 絵が 画面の 外の ときは 描かない。タブが かくれている ときは 止まる
- 動きを へらす せってい：コマ 64（水を 飲んでいる ところ）で 止まる。おすと しゃべるのは そのまま
- スマホ：はば 360px でも よこに はみださない
