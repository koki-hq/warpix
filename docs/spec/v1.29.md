## v1.28 からの変更

### 製作所だより（`news.json`）

形と 場所は そのまま。新しい ものが 上（同じ 日は news.json の じゅん）：

| 日付 | id | 見出し |
|---|---|---|
| 2026-11-01 | `2026-11-01-link-release`（新しい） | WARPIX LINK を 正式リリースしました |
| 2026-11-01 | `2026-11-01-open` | WARPIX製作所、開店しました |
| 2026-10-18 | `2026-10-18-prerelease` | WARPIX LINK を プレリリースしました |
| 2026-10-16 | `2026-10-16-home` | 開店に むけて、ホームページを 公開しました |

- 開店の 本文から「WARPIX LINK も 正式リリース」を 正式リリースの 記事に うつし、「準備中の 札を はずしました。」と 製作所の しょうかいを 入れた
- プレリリースの 本文から「まずは 知り合いに…」を けし、「開店に さきがけて ひと足 さきに 公開しました」に
- これからの 作品も「〇〇 を プレリリースしました」→「〇〇 を 正式リリースしました」の 2 本で 同じ 形に できる
- `url` は 残す（ふるい 版の warpix-link の おしらせ欄で つかう）。`tools/open-news.json` の 本文も だよりに そろえた

- `.news a.n-title` の 色は いらなく なったので けした
