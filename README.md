# WARPIX製作所

ドット絵と チップチューンの 世界を ひとつずつ 組み立てる、ちいさな 町工場の ホームページです。

**https://koki-hq.github.io/warpix/**

ページを開くと、工場の 見取り図が 出てきます。部屋を おすと、その 製品や 場所へ ワープします。

| へや | なに |
|---|---|
| LINK工場 | 踏み台リンクアプリ [warpix-link](https://github.com/koki-hq/warpix-link) へ |
| ???工場 | けんせつちゅう（おすと ピクセが こたえる） |
| ピクセの へや | ピクセの プロフィール |
| けいじばん | 製作所だより（さいしんの おしらせ） |
| じむしょ | 製作所について |

## あそび

- **ピクセ**：ヘルメットを かぶって 中庭を ちょこちょこ あるく。おすと しゃべる。
  まよなか（0〜4 時）は ねていて、おすと「……はっ！ ねてないよ。」
- **えんとつ**：おすと けむりが ぽっ。なんども おすと……。
- **UFO**：ときどき 屋根の うえを warpix-link の UFO が とおる。
- **よる**（19〜5 時）：屋根の まどに あかりが つく。
- `?hour=0〜23` を つけると、その 時刻の 工場を ためせる。

## 製作所だより（news.json）

おしらせは `news.json` に 書くだけ。ホームページの けいじばんと 一覧に 出ます。
warpix-link も この ファイルを 読みにきて、ピクセが「ニュースが あるよ」と 教えます。

```json
{
  "news": [
    {
      "id": "2026-10-16-home",
      "date": "2026-10-16",
      "title": "40 文字まで",
      "body": "ひとこと（なくても いい）",
      "url": "https://...（なくても いい。https だけ）"
    }
  ]
}
```

- `id` は かぶらないように（warpix-link が「もう 読んだ」を おぼえるのに 使う）。
- 日付が 14 日 以内の ものに NEW が つきます。
- 新しい 順に ならべなくても、ページの ほうで 日付順に します。

## ファイル

| ファイル | なに |
|---|---|
| `index.html` | ページの 中身 |
| `style.css` | 見た目（warpix-link と おなじ 紺・ピンク・シアン） |
| `factory.js` | ドットの 絵、ピクセ、えんとつ、UFO、工場の とけい、製作所だより |
| `news.json` | 製作所だより |
| `favicon.svg` | ヘルメットの ピクセ（`node tools/favicon.mjs` で つくる） |
| `tests/` | テスト（`node tests/run.mjs`、7 件） |
| `tools/health.mjs` | 健康診断（重さ・スマホでの速さ・待機中の CPU・アクセシビリティ） |

うごく ものは ぜんぶ 1 つの「工場の とけい」（0.3 秒ごと）で いっしょに 1 コマ すすめます。
ばらばらに うごかすと 画面を なんども 描きなおして 電池を つかうからです。
動きを へらす せっていの ときは、なにも うごきません。

このページは ブラウザに なにも 保存しません。
