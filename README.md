# WARPIX製作所

ドット絵と チップチューンの 世界を ひとつずつ 組み立てる、ちいさな 町工場の ホームページです。

**https://koki-hq.github.io/warpix/**

ページを開くと、入道雲の そびえる 青空の 工場まちが 画面いっぱいに 広がります。
まんなかでは 職人の ゲンさんと、黄色い ヘルメットの ピクセが いっしょに はたらいています。
下へ スクロールすると、地面の 下の、だれも 知らない 世界へ もぐっていきます。

## あそび

- **なかまたち**：ピクセ・ゲンさん・ねこ・ハコビ・バチ・リフトン・アームさん・スズメ・ソラマメ号、みんな おすと しゃべる
- **えんとつ**：おすと けむりが もくもく。なんども おすと……
- **ラジカセ**：おすと チップチューンが 鳴る（3 きょく。おす たびに つぎの きょく、さいごは とまる）
- **見学ツアー**：「▶ 見学ツアー」で ピクセが 工場まちを あんない（さいごは 地面の 下へ）
- **ゲンさんの 一日**：朝は ラジオ体操、昼は おべんとう（スズメに 注意）、3じは おやつ、夕方は かたづけ、夜は うたたね
- **お話**：ゲンさんが トンテンカン → ピクセが 水を とってくる → ごくごく → 汗を ふく → ぷはー（約 29 秒で ひとまわり）
- **時計塔**：ほんとうの 時刻で 針が うごく
- **季節**：春は さくら、夏は 入道雲、秋は すじ雲と もみじ、冬は 雪化粧（`?month=1〜12` で ためせる）
- **地面の 下**：表土 → 粘土（化石）→ 洞窟（水晶・地底湖）→ 古代文明 → 最深部。生き物を おすと こたえる
- **地下の なぞ**：地層ごとに かくれた 石板の かけらを 5 つ あつめると……いちばん 下の さらに 下で、なにかが ひらく
- **せいひん 展示室**：warpix-link の 紹介（できること・つかいかた・製品の 札）
- **なかま図鑑**：5 種族・14 人の なかまたち。「会いに いく」で 絵の 中の その なかまへ
- `?hour=0〜23` で あいさつ・時計塔・ゲンさんの 一日の 時刻、`?t=0〜95` で お話の その コマに とめる

世界観は [docs/THEME.md](docs/THEME.md)、バージョンごとの 仕様は [docs/spec/](docs/spec/README.md)。

## 製作所だより（news.json）

おしらせは `news.json` に 書いて、`node tools/fonts.mjs`（新しい 文字を フォントに 入れる）。ホームページの けいじばんと 一覧に 出ます。
warpix-link も この ファイルを 読みにきて、ピクセが「ニュースが あるよ」と 教えます。

```json
{
  "news": [
    {
      "id": "2026-10-16-home",
      "date": "2026-10-16",
      "title": "40 文字まで",
      "body": "ひとこと（なくても いい）",
      "url": "https://...（なくても いい。https だけ）"
    }
  ]
}
```

- `id` は かぶらないように（warpix-link が「もう 読んだ」を おぼえるのに 使う）。
- 日付が 14 日 以内の ものに NEW が つきます。
- 新しい 順に ならべなくても、ページの ほうで 日付順に します。

## ファイル

| ファイル | なに |
|---|---|
| `index.html` | ページの 中身 |
| `style.css` | 見た目（青空・紙の パネル・地層） |
| `factory.js` | 青空の 工場まち、ゲンさんと ピクセの お話、おせる ところ、製作所だより、図鑑の 絵、工場の とけい |
| `chika.js` | 地面の 下の 世界 |
| `radio.js` | ラジカセの チップチューン（音を ブラウザで つくる） |
| `news.json` | 製作所だより |
| `tools/fonts.mjs` | つかう 文字だけの フォントを たのむ（文字を ふやしたら `node tools/fonts.mjs`） |
| `og.png` | 共有カード（`node tools/og.mjs` で つくる） |
| `favicon.svg` | ヘルメットの ピクセ（`node tools/favicon.mjs` で つくる） |
| `docs/` | 世界観（`THEME.md`）と 仕様メモ（`spec/`） |
| `tests/` | テスト（`node tests/run.mjs`、16 件） |
| `tools/health.mjs` | 健康診断（重さ・スマホでの速さ・待機中の CPU・アクセシビリティ） |

うごく ものは ぜんぶ 1 つの「工場の とけい」（0.3 秒ごと）で いっしょに 1 コマ すすめます。
ばらばらに うごかすと 画面を なんども 描きなおして 電池を つかうからです。
画面に 見えて いない ものは 描きません。動きを へらす せっていの ときは、なにも うごきません。

このページは ブラウザに なにも 保存しません。
